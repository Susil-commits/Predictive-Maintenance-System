# Security Policy

## Supported Versions

The following versions of the Predictive Maintenance System (`PMS`) currently receive security updates and patches:

| Version | Supported          |
| :---    | :---               |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Responsible Disclosure & Reporting a Vulnerability

We take the security and integrity of our codebase, telemetry pipelines, and machine learning models seriously. If you discover or suspect a security vulnerability, we appreciate your efforts to disclose it to us responsibly.

**Please do NOT disclose vulnerabilities publicly in issues or discussions.**

To report a vulnerability responsibly:
1. Email your report directly to **`susilnayak2004@gmail.com`** with the subject line `[SECURITY DISCLOSURE] Predictive Maintenance System`.
2. Include a detailed description of the vulnerability, reproduction steps or proof-of-concept (PoC), and potential impact.
3. We acknowledge reports within **48 hours** and will provide regular status updates until the issue is patched and verified.
4. Once a fix is released in main/production, appropriate credit will be given in release notes if desired.

Thank you for helping keep the Predictive Maintenance System secure.
